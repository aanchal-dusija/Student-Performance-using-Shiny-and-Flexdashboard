# Student Performance using Shiny and Flexdashboard

Website: https://aanchal-dusija.shinyapps.io/hw3shiny/

This repository contains a project focused on analyzing student performance data using R Shiny and Flexdashboard for interactive data visualization and reporting.

### Features: 
- Interactive Dashboards: Created using Shiny and Flexdashboard for dynamic data exploration.
- Data Analysis: Statistical analysis to uncover insights into factors affecting student performance.
- Visualizations: Various plots and charts to illustrate findings and trends in the data.
